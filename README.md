软件播放
软件特性：
1. 支持HTTP、RTSP协议播放；
2. 支持本地IPTV节目回看（7天内）；
3. 支持本地视频、音频播放；
4. 支持WebDav、常见视频、音频格式播放；
5. 支持视频录制，同时提供PC和Android客户端；
6. 支持PC端数字键盘快速选台播放，快进，快退，截图等操作；
7. 支持外挂电影字幕；
8. 支持本地IPTV EPG数据优先显示，同时支持网络EPG数据地址自定义，自动定时更新EPG数据；
9. 支持频道别名映射多数据源映射。
